Enterprise IT Services
Password Reset Policy

Document ID: IT-ACC-001
Version: 1.0
Department: IT Services

1. Purpose

This policy defines the approved process for employees who need to reset
their company password.

2. When a Password Reset Is Required

Employees should request a password reset when:

- They have forgotten their password.
- Their password has expired.
- They are unable to authenticate using their current password.

3. Password Reset Process

Employees should use the approved Enterprise Self-Service Password Portal.

The employee must verify their identity using the registered MFA method.

After successful identity verification, the employee can create a new password.

4. Password Requirements

The new password must:

- Meet the minimum password complexity requirements.
- Not reuse recently used passwords.
- Not contain easily guessed personal information.

5. Security Requirements

Employees must never:

- Share their password with another person.
- Share MFA verification codes.
- Store passwords in unsecured locations.

IT Service Desk personnel will never ask an employee to provide their
password or MFA verification code.

6. Support

If self-service password reset fails, the employee should contact the
IT Service Desk and provide the error message.

Employees must not provide their password or MFA code to the support team.
